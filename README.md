Запуск проекта:
1. Смотрите модуль demo!
2. Main class: com.example.demo.MyClassKt
3. Запускайте в Android Studio или Intelij Idea, IDE должно само определить и предложить установить нужную версию JDK.
4. Для модуля demo андроид зависимости не требуются, но если всё равно не будет запускаться, то уберите подключение app модуля из корневого грэдл файла, а если не поможет, то всё же придётся установить SDK
